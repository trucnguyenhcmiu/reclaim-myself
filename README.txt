RECLAIM MYSELF — Android PWA starter
To install on Android:
1. Upload all files in this folder to a static HTTPS host (e.g. Netlify or GitHub Pages).
2. Open the HTTPS site in Chrome on Android.
3. Chrome menu ⋮ > Install app / Add to Home screen.
4. Data is stored locally in this browser. Export JSON backups regularly.
5. In ChatGPT, attach the exported JSON and ask for an analysis.
This build does not sync to a cloud database. Data is not sent anywhere unless you export and share it.
